# Dynamic Programming
- `Those who can't remember the past are condemned to repeat it. - DP`
- In DP we've
    - <u>Problem Overlapping</u>: if there is no overlapping problem then there is no DP.

    - <u>optimal Sub-Structure</u>
- There are two ways to apply DP:
    - Top-Down/memorization- Recursive
    - Bottom-Up/Tabulation- Iterative
